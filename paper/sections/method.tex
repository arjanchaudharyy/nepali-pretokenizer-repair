\section{Repairing a deployed tokenizer}
\label{sec:method}

The repair has three parts. We edit the regex, learn new merges on top of the existing ones, and initialise the new embeddings so that the model behaves exactly as before on old tokens.

\paragraph{Regex edit.} We add \pM{} to the word class and exclude it from the optional leading character and from the punctuation class. A mark can then only be matched as part of a word, so it stays with the letters around it. For the Llama-3 and Qwen pattern this takes two string substitutions that edit three character classes (Appendix~\ref{app:regex}); digits, contractions, whitespace and punctuation are handled as before. We call the result the \emph{repaired regex}. Qwen3.5 ships almost the same word branch~\citep{land2026smallbugs}.

\paragraph{Continued BPE.} Following \citet{purason-etal-2026-teaching}, we pre-tokenize Nepali text with the arm's regex, segment every pre-token with the original merges, as the deployed model sees it, and run BPE over these segmentations with each base token as an indivisible symbol. The $K$ new merges are appended after the existing ones, so the original merges act first. We discard any merge whose output contains no code point in U+0900--U+097F, together with merges that depend on it. \RI{} and \RII{} run this procedure on the same text with the same $K$ and differ only in the regex.

\begin{proposition}[English invariance]
\label{prop:lossless}
Let $s$ be a normalised string that contains no combining mark (\pM{}) and no code point in U+0900--U+097F. Then the repaired tokenizer \RII{} and the original tokenizer produce identical token ids for $s$.
\end{proposition}
The proof is in Appendix~\ref{app:proof}. The proposition covers ASCII English and code and every script whose normalised text has no combining marks. It does not cover other scripts that use marks: the general repair changes the pre-tokens of 61 of the 204 FLORES-200 languages, including Arabic, Bengali and Thai, whose tokenization the base model has seen only in its original form.

\paragraph{A Devanagari-only repair.} Admitting only the 34 combining marks of the Devanagari block, instead of all of \pM{}, gives a stronger guarantee by the same argument: token ids are unchanged for every input without a code point in U+0900--U+097F. On FLORES-200 this variant changes pre-tokens only in the ten Devanagari languages, and on FLORES Nepali its \RII{} token ids are identical to the general repair's. On a 275\,MB sample of FineWeb-2 Nepali, 24 of 49{,}462 lines are pre-tokenized differently, all because of marks from other blocks, such as emoji variation selectors and Kannada vowel signs (Appendix~\ref{app:regex}). We recommend this variant for deployment. All experiments in this paper, and the released tokenizers, use the general repair.

\paragraph{Embedding initialisation.} Each new token's input and output rows are set to the mean of the rows of its constituent base tokens~\citep{gee-etal-2022-fast}, obtained by applying the original merges to its byte-level string. Original rows are untouched, so on any input whose ids are all original the resized model gives the same logits for every original token as the base model; on an English probe the largest difference is below $10^{-4}$. The new tokens do add terms to the softmax denominator, and continued pretraining is needed to train them.

\paragraph{Loading pitfall.} The transformers class \texttt{Qwen2Tokenizer} rebuilds the pre-tokenizer from a hard-coded pattern when it loads, which silently undoes a repaired regex stored in \texttt{tokenizer.json}. Our released tokenizers therefore set \texttt{tokenizer\_class} to \texttt{PreTrainedTokenizerFast}, and we check after loading that the premium matches the paper.

\paragraph{Arms.} \RO{} (no extension) keeps the original tokenizer. \RI{} (standard extension) appends $K$ merges learned under the original regex, as in \citet{purason-etal-2026-teaching} and \citet{yamaguchi2026lowres}. \RII{} (repair + extension) switches to the repaired regex and appends $K$ merges learned under it.
